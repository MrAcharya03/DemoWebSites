# CSS Units, Box Model, and Fonts Demo

A basic web layout experiment demonstrating the use of viewport units, CSS box model resets, custom fonts, and gradient styling[cite: 1, 2].

## File Structure

- `index.html` - Main HTML document containing an image card and a button element[cite: 1].
- `style.css` - Stylesheet managing layout sizing, resets, image formatting, and button gradients[cite: 2].

## Concepts Used

- **CSS Box Model Reset:** Using `box-sizing: border-box` along with margin and padding resets across all elements[cite: 2].
- **Viewport Units:** Utilizing `vw` and `vh` for sizing containers, heights, and font dimensions relative to the viewport[cite: 2].
- **Styling & Gradients:** Applying border-radius, font styling, and background linear gradients.
