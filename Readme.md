# Laundry Wallah / Laundry Mart

A simple, user-friendly webpage for **Laundry Wallah / Laundry Mart**, providing essential information on laundry services, pricing, and an online booking system.

---

## 📌 Features

* **About Section**: Overview of the business's commitment to quality garment care.
* **Services List**: Detailed breakdown of available services (Washing, Ironing, Dry Cleaning, Express Services, etc.).
* **Price List Table**: Quick reference table for service rates.
* **Booking Form**: Simple online form allowing customers to reserve services by entering their name, email, and phone number.
* **Contact Information**: Direct link for email inquiries.

---

## 🛠️ Built With

* **HTML5**: Semantic markup for layout and form management.
